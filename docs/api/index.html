License: Uso restrito a integradores autorizados pelo Chefe Coruja

Consulta de pacientes, atendimentos, leitos e produção SUS, só leitura e por unidade.

API pública do Chefe Coruja para integradores autorizados: secretarias de saúde, regulação, hospitais parceiros e empresas contratadas.

Situação: este é o contrato da versão 1. A implementação é a tarefa 7 da Fase 3 do BACKLOG. Até ela entrar no ar, os endereços respondem 503.

Acesso

  • Cada integrador recebe uma chave criada pelo administrador do Chefe Coruja. A chave vale para as unidades e os recursos liberados nela.
  • Mande a chave no cabeçalho Authorization: Bearer <chave>.
  • A chave aparece uma única vez, na criação. O sistema guarda só o hash dela. Se perder a chave, peça outra; a antiga é revogada.
  • Toda consulta fica registrada na auditoria do Chefe Coruja: chave, recurso, unidade, horário e resultado.
  • Use só HTTPS.

Dados do paciente (LGPD)

A API entrega o mínimo necessário para a integração:

  • nome e nome social, nascimento, sexo e CNS;
  • o município de residência;
  • o CPF só quando o paciente não tem CNS.

Ficam fora: endereço, telefone, nome da mãe e dados clínicos. A exceção é o atendimento, que traz a cor da classificação de risco, o CID principal e a situação.

Limite de consultas

  • O limite é por chave e por minuto. Ele é informado nos cabeçalhos RateLimit-Limit, RateLimit-Remaining e RateLimit-Reset.
  • Acima do limite, a resposta é 429, com Retry-After em segundos.

Paginação

  • As listas devolvem dados e proximo_cursor.
  • Para a página seguinte, repita a consulta com cursor=<proximo_cursor>.
  • Quando proximo_cursor vem null, a lista acabou.
  • limite vai de 1 a 100 (padrão 50).

Formatos

  • Datas e horas em ISO 8601 com fuso (2026-10-10T14:30:00-03:00).
  • Datas puras como AAAA-MM-DD.
  • Competência SUS como AAAAMM.
  • Identificadores são UUID.

Erros

Os erros seguem o RFC 9457 (application/problem+json): type, title, status, detail, codigo e requisicao. Guarde o valor de requisicao (o mesmo do cabeçalho X-Request-Id) para falar com o suporte.

Versões

  • A versão vai no caminho (/v1).
  • Campo novo não quebra a versão: ignore os campos que você não conhece.
  • Mudança que quebra compatibilidade vira /v2. A versão anterior é mantida por pelo menos 6 meses, com aviso no cabeçalho Deprecation.

Pacientes

Identificação mínima do paciente (LGPD), por busca exata.

Busca exata de paciente por CNS ou CPF

Não há listagem livre de pacientes. A busca é exata, por CNS ou por CPF (um dos dois), e só dentro da unidade informada.

chave
query Parameters

required
string <uuid>

Unidade consultada; precisa estar liberada na chave.

cns
string^[0-9]{15}$

CNS com 15 dígitos.

cpf
string^[0-9]{11}$

CPF com 11 dígitos.
